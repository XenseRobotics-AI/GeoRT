# 阶段一：实际训练效果对照

2026-09-16，先使用现有3498帧，无新增采集。所有模型直接输出，不叠加运行时修正。
先做seed0三路pilot，验证能否形成候选，再决定是否值得做多随机种子确认；pilot不自动提交验收。

- 冻结父模型：标准seed0/w_collision=0/last，作为效果参考。
- C0：仅继续原几何目标。
- C1：指尖输入，增加末节轴向、相邻骨段相对方向、整指背伸偏好。
- C2：C1相同目标，增加骨骼局部输入，关闭全手上下文。
- 共同预算：1000优化步、batch64、lr1e-5；随机采样流与目标点云相同。
- 新目标初值：axis=.05、shape=.02、posture=1；保持原coverage/pinch权重，relation关闭。
- 训练[0,2000)，验证[2100,2448)；测试[2548,3498)暂不用于pilot选参。
- 每100步保存验证分项曲线与快照，验证全集而非随机相邻拆分。候选选择只看验证段。

开发阶段的验收筛选门槛（试验前记录，不代表硬件规格）：
1. 四根非拇指严重PIP/DIP反弯平均占比至少下降80%；不得转移到某个手指形成新的主要异常。
2. MCP过伸帧占比不得相对父模型增加超过5个百分点。
3. 相对父模型指尖位置偏移P95 <=5mm、各对捏平均site间距变化<=2mm，作为行为保持代理而非真实操作误差。
4. 最大关节帧间跳变不得比父模型增加超过5°，并检查运动幅度/静止段变化，不能靠不动通过。

若没有候选同时过关，分析哪一项目标冲突，不把单一反弯率下降称为成功。
同一录像、父模型见过验证段、开发已看过测试段，最终仍需要独立会话验收。
