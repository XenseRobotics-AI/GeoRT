# 阶段三：新增信息与学习能力的受控验证

回顾开发目标：优先方向、多指关系和精细控制，不以反弯或父模型位置保持单项宣称成功。阶段二的骨骼头平均只修正0.0417°，无法据此判定骨骼信息无效。

预先固定：seed42；T2 best基础网络冻结（包括BN缓冲）；全手上下文关闭；原始父模型仍作为原位置/MCP参考；沿用阶段二训练标签、划分、任务loss与feasible mask。残差仍为0.1*tanh(logit)，机械范围不变。共2500步，前1000步标签拟合，batch64，局部头学习率显式为1e-3。两组相同初始化、采样、预算与参数数量。

- H0：局部头只读指尖；15维输入中轴向/有效性12维明确置零，是有意的信息消融，不是把缺失方向当监督。loss仍读取真实骨段。
- H1：相同局部头读取指尖、真实骨段方向和有效性。

比较冻结基础网络、H0、H1、原始GeoRT和现用Wuji滤波/未滤波输出。按相同验证目标选择best；报告训练标签拟合、局部头实际作用、末节方向、MCP/PIP/DIP、位置/开口与局部响应。没有全手上下文收益结论；不使用测试段挑权重。

同时增加共用loss评估。静态输出可以计算coverage、pinch、axis、shape、posture、relation与anchor；response_direction/flatness需要同一输入的扰动重算，不能从顺序缓存虚构。Wuji扰动评估固定每帧开始的优化器/滤波历史，扰动分支不推进真实历史；GeoRT使用相同扰动和FK。原Neural FK给出训练口径，同时报告精确FK复核。anchor与参考MCP是相对父模型的偏好，不作为公平的算法总排名。relation当前权重为0，保留原始/归一化指标。无碰撞loss训练和时间戳，不编造碰撞、速度或延迟指标。

验收仍按阶段二多项门槛；训练头能学习不等于系统质量通过。若H1仍无信息收益，先记录邻近指尖但不同方向样本覆盖，再决定是否采集专项Manus动作。
