SDK公开API只有 `for_hand / step / reset`，无法导出或设定内部目标权重、骨段尺度、滤波系数、求解器参数，也不提供未滤波输出。因此不以同一输入、同一显示资产冒充内部目标相同。已向用户明确该限制；本轮按可核验的端到端/稳态对照继续。

固定版本与生产配置不变。`scripts/audit_wuji_sdk_equivalence.py` 使用验证集每段8个均匀姿态，共72个；每个姿态独立reset、重复80次，保存全过程、末10步变化、末10步均值。SDK再做一次统一刚体变换检查。所有输出按关节名称、弧度和共同精确FK比较，不额外剪裁或滤波。

旧求解器的四组控制：生产配置；仅替换成SDK包内的右手Hand2 URDF；仅把骨段尺度设为1；同时替换两者。后二类只用于解释差异，不替换用户确认的生产对照。SDK包内资产由唯一解剖关节集合识别、记录二进制与URDF哈希，但公开接口不能证实运行时加载了它，因此属于资产交叉诊断，不足以宣称实现等价。

## 两轮的共同约束

- seed42；仅train01训练、val01选型，原始GeoRT、当前M1、生产Wuji及SDK保留。测试会话在最终模型与评估方案冻结后才启用一次；不能看测试结果再调整。
- 原始权重、采集数据、生产配置和默认推理入口不覆盖。所有新权重显式命名并给出实时/录像预览命令。
- 首轮针对可信碰撞约束与局部响应；第二轮根据首轮结果作一次针对性修正。每轮开始前记录确切目标、系数、初始化、训练步数与选型规则，不看结果后变更该轮规则。
- 每轮主模型最多2000个更新步，batch128；实现正确性检查与碰撞监督核验不算效果训练。不得以修复代码为由追加第三轮效果搜索。
- 旧碰撞分类器不直接复用：在原有1800条共同抽检读数上，它对M1中>2mm穿透的召回仅46.95%（820条），对生产Wuji为46.70%（182条）。这不是新的训练结果；记录见 `reports/stage5/collision_surrogate_audit.json`。
- 不把仅消反曲、骨轴误差下降、模型模仿Wuji或总loss下降视作完成；近捏合的site距离也不当接触真值。

## 训练前固定的筛选门槛

以下是工程筛选阈值，不是统计显著性或实机安全承诺。基准是用户确认的生产Wuji，SDK额外列出，不因SDK更差而降低门槛。

1. 相同1800个验证读数上，>2mm穿透比例不超过生产Wuji+2个百分点，>5mm不超过+1个百分点；同时报告每任务，不能靠别的任务平均掩盖明显退化。
2. 对有至少30条样本的15–30mm和30–60mm捏合开口分组，开口代理误差不超过生产Wuji+1mm。<15mm单独报告site间距和穿透，不能通过重叠手指获得“更好的捏合”。
3. 微调同时对照原始输出与双方LP=0.3：12个幅度/间隔单元至少10个的响应方向误差不超过相应Wuji条件+2°，并核查低响应比例、增益偏离1及停手抖动没有系统性恶化。SDK内部LP未知，不能加入“同滤波”排名。
4. 全手方向误差不高于对应Wuji条件，并逐指报告。较小方向误差只有在前述操作质量门槛同时通过时才算可保留的收益。
5. 通过离线筛选只获得真人仿真验收资格；不能据此宣称真人遥操、物理接触或实机部署成功。

## 停止规则

第二轮后若候选仍明显穿透、捏合/微调显著落后，记录失败并停止GeoRT效果迭代，保留可复现实验，回到Wuji路线。若离线通过，则只安排一次同场真人验收，由用户判断实际手感；不自动开启第三轮训练。停止路线不等于删除仓库或历史结果。

## 第一轮冻结设置（主模型训练前记录）

`stage5_R1_seed42` 从 M1 best 初始化，原逐指架构与全部原几何项不变；Adam lr=0.0003，2000步，batch128，seed42。加入冻结的穿透深度近似器：`mean(relu(depth_mm-0.5)^2)/4`，系数1。近似器只用train01映射输出、归一化关节扰动和均匀几何姿态，标签由共同SAPIEN模型生成；其2000步拟合独立于主模型训练预算。

局部响应项使用同一训练片段相隔1/3/6/12次读取的真实姿态，比较人/机器人指尖位移向量，固定目标增益1，输入幅度0.5–10mm，3mm容差平方归一化，系数0.2。它是局部静态映射监督，不是带采集时钟的速度或时序训练；不合成骨骼扰动，不用Wuji作为teacher。

在step0及每500步选型：原固定几何验证目标 + 加权局部响应项 + `10×实际>2mm比例 +20×实际>5mm比例`；碰撞使用每任务均匀32条验证姿态，共288条。最终验收仍用原固定1800条，不以近似器预测代替真实几何。若所有更新变差允许选择step0，不能隐瞒无收益。

## 第二轮冻结设置（主模型训练前记录）

第一轮1800条抽检>2mm降到3.39%，但open_close中>5mm仍10.5%（生产Wuji 0.5%）；微调方向原始/LP条件分别12/12、11/12通过+2°门槛，但增益偏离1分别11/12、10/12单元更差。七个足量小开口分组均通过。第二轮针对残余深穿透和增益，不改筛选门槛。

`stage5_R2_seed42` 从 R1 best 初始化，新增可选全手分支75→64(SiLU)→20，最后一层置零，使初始输出完全保留父模型；归一化输出通过tanh加法式合成，预激活修正限幅0.25。其余网络参数同样可训练。使用R1 train输出附近几何样本与首轮样本合并重新拟合碰撞近似器；碰撞系数2、局部响应训练系数1（选型仍使用0.2，以保持两轮评分定义一致）。其余几何项、数据、Adam lr=0.0003、seed42、2000步、batch128均不变。

这是受两轮预算约束的组合修正，不能把收益单独归因于全手上下文；没有纯上下文消融，不会额外训练第三轮来补齐。若第二轮仍失败，按既定停止规则执行。

第二轮主模型启动前的监督检查：均匀重拟合对R1验证残余穿透仅44.26%检出，故该准备权重未用于主模型。保留几何划分不变，改为每batch 64条局部正例、64条局部样本、128条全部训练几何，低估>2mm深度的Huber权重4；另做2000步监督准备，选择全局/局部留出几何损失等权最低值。最终采用`collision_r2_focused`，残余检出率63.93%，仍有漏检风险，必须用实际几何选型/验收；没有验证姿态或标签进入监督拟合，也未追加主模型训练轮次。
