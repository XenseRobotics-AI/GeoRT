# Manus → Wuji 重定向开发最终结论

2026-09-17。本轮开发结束，继续使用现用 **wuji-retargeting**，不将 R2 替换为默认部署模型。已经获得骨段方向和构型选择方面的几何收益，但尚未证明这些收益能带来明确的操作成功率、接触质量或操作者负担改善；用户对完整回放的判断是现用方案已足够好。停止追加实验是当前应用的投入与收益决定，不是证明 GeoRT 在所有场景都无价值。

## R2 相比原始 GeoRT 实际改了什么

R2 并不是给原始网络加一个“禁止反弯”开关，而是沿 M1 → R1 → R2 形成的独立实验路径。下表以最终 checkpoint 配置和实际训练代码为准。

| 方面 | 原始主分支（视频第1列） | 最终 R2（视频第2列） |
|---|---|---|
| 输入信息 | 每指仅3维指尖位置，五指独立读取 | 每指15维：标准化指尖位置3维、三根骨段轴向9维、有效性mask 3维；统计量只从train01计算 |
| 逐指网络 | 3→128→128→4，LeakyReLU、BatchNorm、Tanh | 15→128→128→4，SiLU、Tanh，无BatchNorm |
| 全手信息 | 无跨指输入 | 增加75→64→20全手上下文分支；输出层零初始化保持R1初始输出，通过有界tanh组合修正五指关节 |
| 几何计算 | 训练依赖学习到的Neural FK，主要处理指尖几何 | 可微精确FK计算指尖、骨段方向和关节姿态；碰撞仍采用单独的可微近似器 |
| 主要训练目标 | 原始扰动响应方向、Chamfer覆盖、曲率/平坦性、pinch；本次原始重训collision权重为0 | 末节轴向、相邻骨段相对方向、反曲软先验、拇指与其他指的相对向量；再加入穿透深度惩罚、真实局部动作的位移响应 |
| 学习流程 | train01从零训练200轮，5000 updates，AdamW 1e-4，按训练loss选best | M1从零训练2000步；R1接续2000步；R2从R1接续2000步。R1/R2使用Adam 3e-4、batch128，以预先固定的验证几何/响应/实际碰撞评分选型 |
| 视频推理 | 原始模型直接输出，无新增低通 | 网络直接输出再LP=0.3；不做在线优化求解或额外姿态投影 |

R2 保留的具体目标与取舍：

- **方向与手型**：末节轴向权重1、相邻骨段形状权重0.2。形状监督排除拇指不对应的关节链，不把人体关节角当作机器人关节真值。
- **反曲软先验**：权重0.2；非拇指MCP低于−15°、PIP/DIP低于−5°时施加软惩罚。这没有收紧机器人硬限位，也不是推理时硬裁剪，因此并未彻底禁止功能性偏离人体构型。
- **多指关系**：权重0.1，匹配尺度校正的拇指—其他指相对向量；人体间距小于15mm不施加这项监督，避免把site强行吸附当成接触。其代价是近捏合缺少充分的操作监督。
- **碰撞**：用训练会话输出附近的真实SAPIEN穿透标签拟合深度网络，在主模型训练时冻结该网络，但梯度可传到关节输出。R2重采样剩余碰撞难例，系数从R1的1提高到2；惩罚为 `mean(relu(depth_mm-0.5)^2)/4`。最终验收仍用实际几何，不能把近似器当安全保证。
- **局部响应**：真实同片段的相邻/近邻读取对，人手指尖位移0.5–10mm时约束机器人位移；尺度3mm，目标增益1。R2训练权重从0.2提高到1。它是位移响应项，不是依赖准确时间戳的速度或加速度监督。

最终 R2 **没有保留**原始coverage/pinch训练项，也没有启用父模型指尖anchor（权重0）、在线离散选解或后置禁止反曲投影；没有使用Wuji输出作为teacher，没有人机成对关节标签。早期离线选解、父模型锚定及分类式碰撞约束保留在历史实验代码中，不应描述成最终R2运行链路的一部分。

这些属于输入、网络、损失与选型流程的组合变化，训练预算和滤波条件也不同。尤其R2相对R1同时加入上下文、刷新碰撞监督并加大响应权重，缺少纯上下文消融，所以不能把改善单独归功于某一个模块。原始模型在本轮结尾才重训，R2不是以这个新原始checkpoint继续微调的。

实现入口：[网络](../geort/manus_model.py)、[几何目标](../geort/coordination_loss.py)、[两轮训练](../geort/train_refinement.py)、[碰撞监督](../geort/collision_surrogate.py)。归档的 [R2配置](final_evidence/r2_config.json) 和 [R2实验元数据](final_evidence/r2_experiment.json) 给出实际启用参数。

## 可以得出什么结论

原始 GeoRT 重训后大幅缓解了旧数据失配，但指尖输入不足以唯一确定中间指节构型和末节方向；最终结果仍有方向表达上的不足。这个信息限制无法仅靠 PD 控制补回。

R2 的真实收益是：引入骨骼信息和构型约束后，末节方向、开口代理及静态可行性有所改善；完整视频的统一 PD 没有消除其方向和开口指标优势。因此不能把本轮结果概括成“GeoRT 只剩可迁移性”或“R2 没有任何改善”。可迁移性本身也没有通过跨机器人、跨操作者实验证明。

但几何优势没有转化为已验证的操作优势。R2 的近闭合 site 距离更大，减少穿透可能同时减少闭合程度；没有物体接触真值时，不能把它称为捏合更好。此前完整 test 的小幅动作响应指标中，R2 与仓库版的增益偏离1分别为0.421和0.429，差异也远小于方向误差上的差异。现有回放不足以证明这种几何改善值得承担学习方案的数据采集、训练与维护成本。

Wuji 仓库版仍是当前应用的选择。SDK 在部分几何指标上更好、部分更差，没有全面占优的证据；本轮不以此自动切换 SDK 版本或替换现用配置。

## 验证边界与仓库状态

- 数据来自同一操作者、同一标定条件下独立采集的 test01；不代表跨人、跨标定或跨机器人泛化。
- 视频 PD 使用 kp=400、kd=10、10Nm上限，控制600Hz、物理1200Hz；各段同一初态并保留起步过程。这是统一仿真参数，不是已标定的实机执行器。
- 60Hz 是离线时间假设。缺少 SDK 采集时间/帧号，不能据此报告实测端到端延迟。
- 本轮视频全部帧数及完整解码验证通过；归档时111项本地 unittest 通过。没有物体操作或实机驱动验收，不宣称远端 CI 通过。
- 保留原始入口、旧 checkpoint 和默认设置；实验功能显式启用。保留阶段报告作为历史证据，以本文件作为最终结论。
