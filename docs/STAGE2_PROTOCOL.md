# 阶段二：有操作约束的选解一致性与信息消融

开工回顾：[开发目标](DEVELOPMENT_GOALS.md)。上一轮全局姿态loss与回退标签冲突，且压低反弯不保证方向/开口或精细控制改善。本轮不改默认模型，不驱动实机，不增加网络规模，不运行在线修正。

固定：原始seed0父模型、训练[0,2000)、验证[2100,2448)、seed42、batch64、lr1e-5；每组2500步，其中1000步离线机器人标签预训练。保留测试段不用于本轮选择；wuji现用滤波/未滤波缓存仅用于对照，不当真值或训练标签。

先生成训练段的候选池，包含父模型和多起点精确FK优化解。候选必须满足：指尖相对父模型偏移<=2 mm；有效末节方向误差不比父模型恶化超过5°；MCP不比父模型或-15°下界额外背伸超过1°；物理关节范围不变。其余构型偏好是软项。方向/位置候选约束仅相对父模型，不代表已经达到操作者目标。

从同一候选池分别选择：逐帧最优、训练骨骼特征近邻图上的一致选解。图同时读取指尖和实际骨段方向，不能把“同指尖、不同方向”强行合并。无时间戳，不做速度/加速度或时序网络训练。近邻图只使用训练段，图能量和标签操作指标先于训练检查。

消融：
- T0：tip_only，逐帧选择的标签，原姿态监督。
- T1：tip_only，一致选解标签，其他保持T0；隔离选解策略收益。
- T2：tip_only，一致选解标签，姿态偏好仅用于已有自然构型或确实找到更合理解的样本，并保留父模型已有MCP伸展；检查监督冲突。
- T3：skeleton，其他保持T2；隔离新增输入信息收益。全手上下文明确关闭，本轮不据此宣称全手协调有效。

图权重、候选优化权重均为记录下来的起点，不作为已验证最优值。各组相同采样流/预算。只用验证数据选择checkpoint。标签门槛未通过则停止该路线；模型至少满足阶段一门槛，并且方向与开口指标不能比父模型更差，运动幅度不能靠压低输出通过。还需完整报告wuji对照、局部增益/死区、近边界与静止输入响应。没有物体、时间戳或独立会话的数据边界保持不变。
